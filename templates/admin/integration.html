nginx

Add inside the server {…} block for {{ host }}{% if not is_subpath %} (create one if this is a new subdomain){% endif %}, then run sudo nginx -t && sudo systemctl reload nginx.

{% if is_subpath %}location {{ path }}/ {
    proxy_pass http://{{ upstream }};
{% else %}location / {
    proxy_pass http://{{ upstream }};
{% endif %}
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    client_max_body_size 12m;
}

Caddy

Add to your Caddyfile, then run caddy reload. Caddy obtains HTTPS certificates automatically.

{% if is_subpath %}{{ host }} {
    # …your existing site configuration…
    handle {{ path }}* {
        reverse_proxy {{ upstream }}
    }
}{% else %}{{ host }} {
    reverse_proxy {{ upstream }}
}{% endif %}

Apache

Requires mod_proxy, mod_proxy_http and mod_headers (sudo a2enmod proxy proxy_http headers). Add inside the <VirtualHost> for {{ host }}.

ProxyPreserveHost On
RequestHeader set X-Forwarded-Proto "https" env=HTTPS
ProxyPass {{ path or "/" }} http://{{ upstream }}{{ path or "/" }}
ProxyPassReverse {{ path or "/" }} http://{{ upstream }}{{ path or "/" }}

Checklist

  • Public address: {{ site.url }} — change it in Settings if it's wrong.
  • HTTPS: {% if https_seen %}your proxy reports HTTPS. Sign-in cookies are marked secure.{% else %}this page didn't arrive over HTTPS via a proxy. Once your site is connected, make sure the proxy sends X-Forwarded-Proto (included in the snippets above).{% endif %}
  • Port: keep Quill listening on 127.0.0.1 so it's only reachable through your web server. Docker users map the port with -p 127.0.0.1:3000:3000.
  • Check: open {{ site.url }}/. If you see your blog, you're done. A 502 error means the web server can't reach Quill: check that it's running and that the address above matches.
